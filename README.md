# 📖 Devesh Singh — 3D Interactive Dev Codex

> An interactive 3D WebGL scrollytelling developer codex featuring real-time Three.js graphics, origami architecture pop-ups, and live system specs.

Live URL: [https://deveshsingh0710.github.io](https://deveshsingh0710.github.io)

---

## 🛠️ Tech Stack

- **3D Graphics Engine:** [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) + [@react-three/drei](https://github.com/pmndrs/drei)
- **UI & Framework:** React 19, TypeScript, Vite, Tailwind CSS v4
- **Audio Synthesizer:** Native Web Audio API procedural foley effects (zero external MP3 dependencies)
- **Icons:** Lucide React & Custom SVG
- **Deployment:** GitHub Pages via GitHub Actions CI/CD

---

## 📚 Chapters

- **Cover:** Leather & gold hardbound Dev Codex with interactive seal.
- **Chapter I (Genesis):** Engineering philosophy, core toolchain, and rotating 3D gold astrolabe.
- **Chapter II (Quantum Tunneling):** Time-dependent Schrödinger equation simulation with animated wave packet and crystalline potential barrier.
- **Chapter III (LabelChecker):** Computer vision & OCR inspection pipeline with live 3D laser scanner and target detection boxes.

- **Chapter V (Epilogue & Inquiries):** Direct contact links, GitHub connection, and interactive wax seal.
